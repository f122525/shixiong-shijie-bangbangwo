# 师兄师姐帮帮我

这是一个纯前端 PWA，核心计算完全在本机浏览器执行。

主要模块
- C1V1=C2V2 万能稀释
- 连续等比梯度
- 完全培养基/添加剂
- 血球计数板与活率
- 细胞重悬
- 细胞铺板
- CCK-8/药敏加药计算
- 小鼠 mg/kg + mL/kg 按实际体重计算
- 药物/试剂库存与使用扣减
- 计算历史
- JSON 备份/恢复
- 内置公式自检
- 8 个常见实验验证题

iPhone 安装（PWA）
1. 将整个文件夹部署到任意 HTTPS 静态网站。
2. 用 iPhone Safari 打开网页。
3. 分享 -> 添加到主屏幕。
4. 首次打开后，核心页面可离线缓存使用。

本地电脑预览
在该目录运行：
python3 -m http.server 8000
然后访问 http://localhost:8000

注意：本工具只进行数学和流程换算，不替代药品说明书、动物伦理、实验室 SOP 或专业判断。
